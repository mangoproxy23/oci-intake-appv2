# OCI Intake Application

OCI Intake helps teams turn infrastructure inventories and cloud bills into an Oracle Cloud Infrastructure (OCI) migration estimate and bill of materials.

## What it does

- Imports on-premises server and application inventories from spreadsheets.
- Imports AWS, Azure, and GCP bills from PDF, CSV, TSV, XLSX, or XLS files.
- Normalizes source data into an editable review table.
- Maps workloads and services to OCI shapes, services, and rate-card SKUs.
- Supports sizing, licensing, storage, and pricing review before approval.
- Produces OCI estimates, comparison views, downloadable BOM workbooks, and architecture deliverables.

Optional OpenAI assistance can help identify and normalize spreadsheet data and create architecture plans. Core pricing, SKU mapping, and BOM calculations remain deterministic.
